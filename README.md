# Infinixa 2026 - Official Symposium Website
### University College of Engineering, Ariyalur (A Constituent College of Anna University, Chennai)

A futuristic, high-tech, and fully responsive national-level technical symposium website built with HTML5, CSS3 Glassmorphism, JavaScript, and Three.js 3D WebGL animations.

---

## 🚀 Features
- **3D WebGL Hologram World**: Interactive Three.js cyberpunk scene with neural particle dust, floating geometries, and responsive camera navigation.
- **Dynamic Event Arenas**:
  - **Technical Events**: PaperX (Technical Paper Presentation), Prompt Battle (Generative AI), Code Combat (Competitive Programming).
  - **Non-Technical Arena**: Free Fire Esports Tournament & Sketch Hunt (Creative Pictionary).
- **Interactive Mini-Simulations**: Real-time mock testcase streams, Free Fire live telemetry, AI prompt typing, and Sketch drawing guessing game.
- **Campus Location & Navigation**: Embedded interactive Google Map and direct one-click Google Maps navigation to University College of Engineering, Ariyalur.
- **Helplines & Direct Inquiries**: One-tap phone calling and email contact links for student coordinators.
- **Centralized Configuration**: All branding, event dates, registration fees, contact details, and Google Form URLs are customizable in `js/config.js`.
- **100% Responsive Design**: Pixel-perfect layout across mobile (320px+), tablet, laptop, and 4K desktop screens.

---

## 🛠️ Tech Stack
- **Structure**: HTML5 Semantic Markup
- **Styling**: Vanilla CSS3 (Custom Glassmorphism, CSS Grid, Flexbox, Fluid Typography)
- **3D Graphics**: Three.js WebGL Engine
- **Icons**: Lucide Icons CDN
- **Fonts**: Orbitron, Space Grotesk, Inter, Fira Code (Google Fonts)

## 🌐 Deploy to GitHub Pages
1. Push this repository to GitHub.
2. Go to **Settings** > **Pages**.
3. Under **Branch**, select `main` (or `master`) and folder `/ (root)`, then click **Save**.
4. Your website will be live worldwide at `https://<your-username>.github.io/<repo-name>/`!
